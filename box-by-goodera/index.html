Anatomy of a box

Anyone can ship a kit. What arrives in a Goodera box is four things bonded together — and the last one is the reason a CSR team can put it in a report.

Layer one

The kit

Every component counted, sourced and flat-packed. Nothing to buy, nothing to prepare, nothing left over.

Layer two

The volunteering activity

A facilitated session with a run sheet, a host and a duration. Booked for one office or forty-four countries on the same day.

Layer three

The nonprofit partner

Vetted, named and matched before the box ships — drawn from 50,000+ partners across 100+ countries. The box has a destination before it has a build date.

Layer four

The impact report

What was built, how many, which region, which partner received it. Quantified, not described. This is the layer a kit bought off a shelf can never carry.
